# Security policy

## Report a problem privately

If you find a security problem in this package, please tell us privately. Do not open a public issue or pull request with the details.

- Use **Security, Report a vulnerability** on the [BanyanCMS/banyan](https://github.com/BanyanCMS/banyan/security) repository, or
- email <info@solutionforest.net>.

Please include the package version, what you found and how to reproduce it.

We reply within 2 working days and send a first assessment within 5 working days. We tell you when a fix is released, and we credit you if you want.

## Supported versions

| Version | Security fixes |
| --- | --- |
| 0.1.x | Yes |

This package is developed in the [Banyan monorepo](https://github.com/BanyanCMS/banyan) at `packages/filament-media-library`. Fixes are made there and released to this repository.
